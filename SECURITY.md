# Security Policy

## Supported versions

Security fixes are generally prepared for the latest published version. Users should upgrade to the latest release when a fix is available.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature on this repository when it is enabled. Include the affected version, steps to reproduce, and any relevant logs with secrets and personal data removed.

If private vulnerability reporting is not enabled, contact the repository maintainers through their GitHub profile and do not post exploit details or sensitive data in a public issue. Please allow maintainers reasonable time to investigate and prepare a fix before public disclosure.

This repository's GitHub security settings, including private vulnerability reporting, must be enabled by a repository administrator in the repository settings. This file does not enable those settings by itself.
